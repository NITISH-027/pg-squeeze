# PG-SQUEEZE Dashboard

A premium, minimal, engineering-focused observability dashboard for PG-SQUEEZE.

## Setup & Running

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Run in development mode**:
   ```bash
   npm run dev
   ```

3. **Build for production**:
   ```bash
   npm run build
   ```

## Features

* **Overview**: Total connections, short-lived connection counts, and live indicator.
* **Connection Patterns**: Simple, clear visualization of connection profiles.
* **Process Forensics**: Sortable table displaying process metrics.
* **Investigation Guidance**: observation, interpretation, and recommendation.
* **Hotspots**: Displays top contributors contributing to connection churn.
